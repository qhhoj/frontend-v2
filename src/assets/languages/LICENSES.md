# Language logos: sources and licences

The monochrome language marks in this folder are drawn by `LanguageIcon` (`src/components/language/`) as CSS masks in the text colour, never recoloured or reshaped otherwise. They were vendored once from two npm packages, reduced to bare paths and passed through svgo:

- [simple-icons](https://github.com/simple-icons/simple-icons) 16.35.0: CC0-1.0 as a package, except the icons that carry their own licence (listed per file below).
- [devicon](https://github.com/devicons/devicon) 2.17.0: MIT, Copyright (c) 2015 konpa. The `-plain` variants were used with their fills and colours removed.

The marks are trademarks of their owners and are shown only beside the name of the language they stand for. Their use here does not imply endorsement. Several owners publish usage guidelines (for example Python, Rust, Go, Kotlin, Lua and F#); simple-icons lists them in its `data/simple-icons.json` (`guidelines`). See also the [simple-icons disclaimer](https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md).

## Adding a logo

1. Take a single-colour mark from simple-icons (or a devicon `-plain` file) whose licence allows it.
2. Keep only its paths (no fills, styles, scripts or links), run it through svgo and save it as `<family>.svg` here.
3. Map the judge key to that family in `language-icons.ts` and add a row to the table above; `language-icons.node.spec.ts` fails while a file has no row.
