# Clay kit

The only source of control recipes. New code imports from here. Key props only; read the file for the rest. Colours, sizes and radii come from tokens: `docs/design-language.md`, `.claude/skills/qhhoj-web-style/SKILL.md`.

| Need                                 | Part                                                   | Key props / notes                                                                                                                                                                             | Replaces                                            |
| ------------------------------------ | ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| Button, link button                  | `AppButton`                                            | `tone` primary/secondary/ghost/danger, `size` sm/md/lg, `to` or `href`, `loading` (spinner, label kept), `disabled` (aria-disabled), `block`; slot `#icon`. Admin look comes from `.qh-admin` | `buttonClass` in `admin/ui/controls.ts`             |

| Status pill, tag, count              | `Chip`                                                 | `tone` neutral/accent/success/danger/warning/info/`tag-1..8`/verdict code, `size` sm 22 / md 28, `icon`, `dot`, `interactive`                                                                 | `AdminChip`                                         |
| Card                                 | `Card`                                                 | `variant` glass (page card) / inset (tile) / flat (admin), `padding` sm/md/lg, `as`, `title` + `lead` + `#actions` header                                                                     | `GlassCard`, `CARD` in `controls.ts`                |

## Part per job

The standard (sizes, one list/create/save pattern, copy): `.claude/skills/qhhoj-web-style/SKILL.md` §2-§4. Every job below has one part. A part marked "next" is being added by its kit lane (`.batch/ux-audit/PLAN.md` §4); until it lands, use the closest part above and never hand-roll a recipe.

| Job                                                | Part                                                                                                                                    | Never                                                                         |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Inline text action ("Rời kỳ thi")                  | `AppButton tone="link"` (next)                                                                                                          | underlined raw `<button>`/`RouterLink`                                        |
| One toolbar on/off ("Ẩn bài đã giải")              | `AppButton pressed` (next)                                                                                                              | `FilterToggle`, local `TOGGLE`                                                |
| One chip in a set (tags, verdicts, active filters) | `Chip interactive pressed`, `to`, `removable` (next)                                                                                    | local chip recipes                                                            |
| Header round icon button                           | `IconButton tone="secondary"`                                                                                                           | raw `size-11 rounded-pill` buttons                                            |
| Search a list                                      | `SearchInput` (next) inside `FilterBar`                                                                                                 | `ToolbarSearch`, hand search boxes                                            |
| Long pick-list / several values                    | `ComboBox` (next) / `ChipPicker` (admin, next)                                                                                          | PrimeVue copies, comma-separated text                                         |
| Checkbox, radio, card radio                        | `Checkbox`, `RadioGroup`, `ChoiceCards` (next)                                                                                          | raw inputs                                                                    |
| Date and time                                      | `DateTimeField` (next; site zone, "GMT+7")                                                                                              | native `datetime-local`                                                       |
| Markdown text                                      | `MarkdownEditor` (next)                                                                                                                 | raw `<textarea>`                                                              |
| Row actions                                        | one visible `AppButton size="sm"`, the rest in `RowMenu` (next)                                                                         | several text buttons per row                                                  |
| Pager                                              | `NumberedPager` (through `DataTable pager`; `stepper` when the total is unknown); `LoadMore` (next) for comment threads only            | hand prev/next                                                                |
| Selection actions                                  | `BulkBar` (next)                                                                                                                        | hand bars                                                                     |
| Dialog with a form / confirm step                  | `Modal` + `#footer` / `ConfirmDialog tone="danger"`, `TypedCodeDialog` for irreversible deletes                                         | `ConfirmDialog` used as a form, PrimeVue `Dialog` direct, browser `confirm()` |
| Side panel / create-edit of a small record         | `Drawer` (next) / `EditDrawer` (`Drawer` + form + `SaveBar variant="footer"`)                                                           | PrimeVue `Drawer` direct                                                      |
| Loading / empty / error                            | `QueryState` + `#skeleton` / `EmptyState` with one `#action` / `Notice tone="danger"` next to its cause, `StatePanel` for a failed page | "Đang tải…" text, `<p class="text-muted">`, toast-only failures               |
| Success                                            | the `SaveBar` text for forms; a toast (`useToast`, next) for row, bulk and background actions                                           | a toast after a SaveBar save                                                  |
| Show/hide a block                                  | `Disclosure` (next)                                                                                                                     | hand `<details>`                                                              |
| A user                                             | `UserLink`                                                                                                                              | hand profile links                                                            |
| Sections of a page / vertical side nav             | `Tabs` (`to` items, `overflow="menu"`) / `Tabs variant="rail"` (next)                                                                   | `PillTabs`, `AdminTabs`, hand tablists                                        |
| Verdict                                            | one verdict chip (`lib/verdicts.ts`)                                                                                                    | `VerdictBadge` circles                                                        |

Helpers without a visual: `use-row-open.ts` (a row opens its link), `TabsOverflow.ts`, `FormField.control.ts`, `SaveBar.props.ts`, `Card.variants.ts`, `DataTableCheckbox.vue` and `FormFieldError.vue` (parts of `DataTable` and `FormField`), `BrandWordmark.vue`.

Also in `src/components/`: `QueryState` (+ `#skeleton`), `SkeletonBlock`, `StatePanel`, `EmptyState`, `NumberedPager`, `ToolbarSearch`, `ToolbarSelect`. Admin-only (`src/features/admin/ui/`): `AdminRowMenu`, `AdminLeaveGuard`, toasts via `use-admin-toast`.

The wrappers in the last column stay only for the call sites that already use them; ESLint rejects a new import. The ledger and the rule: `docs/wrapper-migration.md`.

Known gaps: `Notice` has no icon override, `Chip` has no `to`, `StatGrid` values are plain strings, there is no toggle button (single `aria-pressed`) primitive. Not built: `ListRow`, `SidebarLayout`, and the parts marked "next" above.
