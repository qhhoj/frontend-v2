# Clay kit

The only source of control recipes. New code imports from here. Key props only; read the file for the rest. Colours, sizes and radii come from tokens: `docs/design-language.md`, `.claude/skills/qhhoj-web-style/SKILL.md`.

| Need                                 | Part                                                   | Key props / notes                                                                                                                                                                             | Replaces                                            |
| ------------------------------------ | ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| Button, link button                  | `AppButton`                                            | `tone` primary/secondary/ghost/danger, `size` sm/md/lg, `to` or `href`, `loading` (spinner, label kept), `disabled` (aria-disabled), `block`; slot `#icon`. Admin look comes from `.qh-admin` | `buttonClass` in `admin/ui/controls.ts`             |
| Icon-only button                     | `IconButton`                                           | `label` (required: aria-label + title), `tone` (default ghost), `size`                                                                                                                        | `controls.ts` icon classes                          |
| Class string for a non-button (rare) | `buttonClasses()` in `button-classes.ts`               | same tones and sizes                                                                                                                                                                          |                                                     |
| Status pill, tag, count              | `Chip`                                                 | `tone` neutral/accent/success/danger/warning/info/`tag-1..8`/verdict code, `size` sm 22 / md 28, `icon`, `dot`, `interactive`                                                                 | `AdminChip`                                         |
| Card                                 | `Card`                                                 | `variant` glass (page card) / inset (tile) / flat (admin), `padding` sm/md/lg, `as`, `title` + `lead` + `#actions` header                                                                     | `GlassCard`, `CARD` in `controls.ts`                |
| Inline feedback                      | `Notice`                                               | `tone` info/success/warning/danger, `title`, `compact` (admin), `bit`, `role`; slots `details`, `action`                                                                                      | `AdminNotice`, `SettingsNotice`                     |
| Form field                           | `FormField` + `TextInput` / `TextArea` / `SelectField` | `label`, `hint`, `error`, `required`/`optional`; inputs read id and aria from the field                                                                                                       | `AdminField`, `AuthField`, `INPUT` in `controls.ts` |
| Save a form                          | `SaveBar` + `useLeaveGuard`                            | `dirtyCount`, `pending`, `savedAt`, `blockedReason`, `variant` page/footer                                                                                                                    | `AdminSaveBar`, `AdminLeaveGuard`                   |
| Tabs                                 | `Tabs`                                                 | `items` (`to` = links, else a tablist with `panelId`), `variant` pill/underline, `overflow` scroll/menu, v-model                                                                              | `PillTabs`, `AdminTabs`, `AdminFilterTabs`          |
| On/off that applies at once          | `Switch`                                               | v-model, `label` or `labelledby`, `description`, `disabled` (aria-disabled) + `#note` for why, `size` md 24x40 / lg 44x56; 44 px hit area on touch. In a form saved later use a checkbox      | `AdminSwitch` adds `lockedBy` on top                |
| One of a few choices                 | `SegmentedControl`                                     | `options`, v-model, `size` md/sm                                                                                                                                                              |                                                     |
| Page title block                     | `PageHeader`                                           | `title`, `lead`, `crumbs`, `back`, `meta`; slots `#start`, `#above`, `#lead`, `#meta`, `#actions`, `#tabs`; the only h1 (raw `<h1` is lint-banned)                                            | `AdminPageHeader`                                   |
| Table / list                         | `DataTable` (+ `DataTableColumns.ts`)                  | `columns`, `rows`, `rowKey`, `density` comfortable 48 px public / compact 40 admin, `stack` card/scroll (`#card` row), `stackBelow`, `stickyColumns`, `rowTo`, `pager`, sort/selected         | `AdminDataTable`                                    |
| Search + filters                     | `FilterBar`                                            | `searchLabel`, `chips`, v-model search                                                                                                                                                        | `AdminFilterBar`                                    |
| Dialog                               | `Modal` (`ConfirmDialog` for confirms)                 | `title`, `size` sm/md/lg (full screen under 640)                                                                                                                                              |                                                     |
| Popover, small menu panel            | `Popover`                                              | `label` or `labelledby`; `toggle($event)` / `hide()`; focus goes in, Tab stays inside, Escape and `hide()` return focus to the opener                                                         |                                                     |
| Facts or stats                       | `StatGrid`                                             | `items` {label, value (string), tone, hint}, `cols`, `mode` fact/stat                                                                                                                         |                                                     |
| Meter                                | `ProgressBar`                                          | `value`, `max`, `tone`, `label`                                                                                                                                                               |                                                     |

Helpers without a visual: `use-row-open.ts` (a row opens its link), `TabsOverflow.ts`, `FormField.control.ts`, `SaveBar.props.ts`, `Card.variants.ts`, `DataTableCheckbox.vue` and `FormFieldError.vue` (parts of `DataTable` and `FormField`), `BrandWordmark.vue`.

Also in `src/components/`: `QueryState` (+ `#skeleton`), `SkeletonBlock`, `StatePanel`, `EmptyState`, `NumberedPager`, `ToolbarSearch`, `ToolbarSelect`. Admin-only (`src/features/admin/ui/`): `AdminRowMenu`, `AdminLeaveGuard`, toasts via `use-admin-toast`.

The wrappers in the last column stay only for the call sites that already use them; ESLint rejects a new import. The ledger and the rule: `docs/wrapper-migration.md`.

Known gaps: `Notice` has no icon override, `Chip` has no `to`, `StatGrid` values are plain strings, there is no toggle button (single `aria-pressed`) primitive. Not built: `MarkdownEditor`, `ListRow`, `SidebarLayout`. Until a part exists, reuse the closest one and never hand-roll a new recipe.
