# qhhoj-frontend-v2

## 2.0.0

- New Vue 3 SPA (Vite, TypeScript strict, Vue Router, Pinia, vue-i18n, Tailwind 4, PrimeVue unstyled) served against `backend-v2` (`/api/internal`).
- API types are generated by `openapi-typescript` from a committed backend OpenAPI snapshot; all calls go through typed `apiGet`/`apiGetPage`/`apiSend`, and `api:check` plus the `api-drift` workflow fail on drift.
- Pinia holds client state only (session, theme, locale); server data lives in vue-query, with the cache cleared whenever the signed-in user changes.
- The client sends `X-CSRF-Token` on unsafe methods, retries once on `csrf_failed`, and unwraps the response envelope into `ApiError`.
- Tested with Vitest (jsdom, @vue/test-utils) and Playwright with axe accessibility checks; design tokens are enforced by `lint:tokens`.

### Contests

- Rules: registering, first join and virtual start ask the viewer to accept the rules; "Quy định" card; editors write rules, set up balloons and see the accepted revision per participant.
- Coloured tag chips, a tag filter row on the list (`?tag=`) and an admin screen for the tag catalogue.
- Problem rail beside the statement while in a contest (statement stays full width until it loads); one limits column (time and memory, dash for hidden problems).
- Balloon queue at `/contests/:key/balloons` (deliver, undo, pending and delivered filters, 10 s refresh) and a printable next-10 sheet; focus stays in the list after a delivery.
- Replay page at `/contests/:key/replay`: player bar, animated board, ghost rows, "Vừa xảy ra" feed, shared second kept in the link; a "Phát lại" tab on ended contests. A refused board (frozen or hidden) drops a loaded board and reads its reason from the backend; "not ready" polls with backoff and offers a retry; big boards redraw only changed rows, skip row slides above 100 rows and avoid deep reactivity; rows stop moving in low-power mode.
- Ranking: during a virtual run of an ended contest, "So với bảng thật" compares the run with the real board and ghosts at the same elapsed time.
- Contest refusals (balloons, export, tags, rules, replay, ghosts) show their own texts.
- Official contest: organization join, request, leave and profile organization reordering are disabled with the reason, and the server's refusal gets the same explanation; the pill, banner and locks follow the end time and live mode changes; the countdown pauses in a hidden tab.

### Admin

- Contest editor: a Ghost tab (preview, replace, download, delete from CSV, refused rows listed); a Data tab with the submissions export and event-feed key (shown once, revoke, release to resolver); an Actions tab with a replay rebuild (queued state, hourly limit) and a publish card (dry run, per-problem outcomes, confirmed publish, auto-publish switch with last outcome).
- Problems: a "Đã xóa" tab (days left, restore, superuser purge-now; a refused purge reloads the list), a danger zone that deletes after typing the code, and a "Tải gói đề" card on the Data tab that builds the package zip. Submissions of a deleted problem keep their page with a "Bài đã bị xóa" notice and an unlinked name.
- Ticket reply templates at `/admin/tickets/canned` (100 cap explained).
- Settings: an organization quota block (mode, default credits and storage, costs); a sortable quota overview at `/admin/organizations/quotas` with an edit form (empty means site default).
- External systems at `/admin/integrations`: create keys (shown once, optional expiry) and revoke; judge keys use the same reveal dialog. A past expiry gets a Vietnamese refusal and expired keys show as expired.
- Short links at `/admin/short-links`: list, create with code and expiry, delete after confirmation.
- Judges: busy/slots and build replace the judged-problem count; a taken name is recognised by the `name_taken` issue code.

### Organizations

- A "Bài tập" tab with tag and archive filters, search, per-row tags and archive; bulk archive, unarchive, tag and untag with a result line per code; tag catalogue management (add, rename, recolour, delete).
- A "Hạn mức" tab for admins: credit and storage meters, warning from 80 %, warn or blocking mode, monthly credit ledger; a limit of 0 reads as blocked under enforcement.
- A notice above a problem that one of your organizations archived.
- Refused creates, clones, uploads and imports name the exhausted quota (needed, left, used), including Polygon import and the problem clone card.

### Tickets and notifications

- Bell with unread badge and a drawer of the latest five, a `/notifications` page filtered by status and kind (including "Khác" for quota warnings), live updates on the per-user stream, an important-notification banner; identical bell rises are announced again.
- Tickets: an alerts strip (assigned to you, waiting for staff), a canned-reply picker in the composer (`{tên}`, `{bài}` filled in), a thread with state changes folded into groups and a 200-event notice; a ticket edit refused because the ticket changed reloads it; reply refusals match by error code.

### Standalone features

- Submission source diff at `/submissions/diff?left=&right=`: side-by-side (one column on phones), word highlights, folded identical runs, moved and whitespace-only labels, named states for forbidden, missing, identical or over-5000-line sides, a "too different to compare" notice for very different large sources; entry points are a compare form on the submission page and a two-row pick on the list.
- Short links: a "Sao chép liên kết ngắn" button (once per page and account) on problem, contest, post, profile and organization headers, with daily limit and blocked clipboard explained; creation refuses a past expiry; a page hidden from a short-link visitor says they may lack permission.
- Low-power mode: automatic on weak devices or Save-Data, switchable on Appearance, its popover and the footer; no blur, blobs or motion, a 60 s ranking poll and a plain code editor with Tab indent (undoable).
